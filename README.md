# Estructura del proyecto

A continuación se muestra la jerarquía de carpetas y archivos del proyecto `l2g2-ejemplo-webpack`.

```
l2g2-ejemplo-webpack/            ← carpeta raíz del proyecto
├── assets/
│   └── js/
│       ├── index.js             ← punto de entrada JS (archivo principal de lógica)
│       └── modules/
│           └── operaciones.js   ← módulo auxiliar
├── dist/
│   └── main.js                  ← bundle generado por webpack
├── index.html                   
├── package.json                 ← dependencias y scripts
├── package-lock.json            
├── README.md                    
└── webpack.config.js            ← configuración de Webpack
```
